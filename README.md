# Подарок на 14 ноября

Интерактивная история в 10 сценах: история идёт от ночи к рассвету.

1. **21** — поздравление и кнопка «Начать»
2. **Торт** — 21 свеча: задуть пальцем или подуть в микрофон
3. **Твоя улыбка** — стереть золото и увидеть первое фото
4. **Твои моменты** — стопка полароидов, листаются свайпом
5. **Твои приключения** — фотографии со скал и из зимнего леса
6. **К морю** — два снимка из путешествия
7. **Когда играет музыка** — концертное видео с управлением звуком и две фотографии
8. **Созвездие** — соединить звёзды в сердце
9. **Конверт** — внутри фотография с букетом и короткая записка
10. **Рассвет** — поздравление и подпись

## Что поменять

Всё содержимое лежит в **`story.js`**: тексты, подписи и пути к файлам.

- **Фото** — снимки лежат в `photos/`. Пути находятся в настройках соответствующих сцен. В `memories.cards` задаётся порядок полароидов, а в `travels.photos` — три снимка из поездок.
- **Музыка** — для «Первой любви» указан путь `assets/first-love.mp3` в `story.js`. Песня запускается при открытии открытки и играет по кругу. Если браузер требует взаимодействия, достаточно коснуться первой страницы или нажать клавишу. Кнопка с нотой управляет воспроизведением, при просмотре ролика со звуком фон становится тише.

## Посмотреть у себя

```bash
cd ~/Gift14november
python3 -m http.server 8000
```

Открой http://localhost:8000. Чтобы сразу попасть на нужную сцену: `?scene=candles`, `first`, `memories`, `travels`, `coast`, `concert`, `stars`, `letter`, `final`.

## Выложить на GitHub Pages

```bash
cd ~/Gift14november
git init && git add . && git commit -m "Gift"
gh repo create gift --public --source=. --push
gh api repos/{owner}/gift/pages -X POST -f "source[branch]=main" -f "source[path]=/"
```

Через минуту сайт будет по адресу `https://<логин>.github.io/gift/`. Микрофон работает только по HTTPS, а GitHub Pages его даёт.

Если не хочешь, чтобы фотографии лежали в публичном репозитории, используй Vercel (`npx vercel`) или приватный репозиторий с GitHub Pages (нужен платный план).
